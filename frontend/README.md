# Campus Customs Ops Floor (dashboard)

React + Vite + TypeScript dashboard for the HW5 agent team. See the root `README.md` for setup.

```bash
npm install
npm run dev        # http://localhost:5173, talks to the backend at http://localhost:8000
```

Set `VITE_API_URL` to point at a different backend. Design notes are in `../output/design.md`.
